## Capstone project

### [DevOps Revision Tracker](capstone-devops-revision-tracker/README.md)

A production-style three-tier revision-tracking application demonstrating automated testing, Docker, GitHub Actions, Trivy, Terraform, Kubernetes, Helm, Prometheus, Grafana, alerting, application logs, and Argo CD GitOps.

- **Application:** React + FastAPI + PostgreSQL
- **CI/CD:** GitHub Actions, Trivy, GHCR, kind, Helm
- **Observability:** Prometheus metrics and alerts, Grafana dashboards, Kubernetes logs
- **GitOps:** Argo CD continuous reconciliation with Synced and Healthy evidence
- **Evidence:** [Complete screenshot gallery](capstone-devops-revision-tracker/README.md#evidence-and-submission)
- **Presentation:** [Capstone slide deck](capstone-devops-revision-tracker/presentation/devops-revision-tracker-capstone-final.pptx)
