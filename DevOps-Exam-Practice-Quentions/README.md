## How to use this folder

1. Open one session file.
2. Attempt the ten MCQs without checking the answer key.
3. Read the short explanation below the answer key only for questions you missed.
4. Read the practical-lab approach and understand why each command is used.
5. Use the full learning notes in `complete-notes/` only when an explanation is still unclear.
